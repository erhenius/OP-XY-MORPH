# Install gui2d2

Keep the working SDK edition from gui2d1. Import Morph_gui2d2_Source.zip as Morph source, select version 1.3.1-dev-gui2d2, and start a fresh Manager build. No SDK reimport is needed.

Check AUX M3 sqrt/linear/exp curves and dynamic filter K1 low cut / K2 compression / K3 distortion / K4 high cut. C and D label the compression/distortion amount bars. Envelope streaks were deliberately left as accepted. Host checks pass; native/device confirmation remains pending.
