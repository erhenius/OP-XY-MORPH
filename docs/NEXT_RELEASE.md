# Current release

gui2d16 is the public Morph source release. Its AUX M3 view shows pad and held-K4 sensitivity with independent arrows. The pad responses use integer lookup tables and the curve artwork follows the sampled responses. The release removes the temporary sweep timing readouts.

gui2d14 is the hardware-confirmed smooth-sweep baseline. See [Validation](VALIDATION.md) for gui2d16 host results and [the illustrated quick reference](Morph-Quick-Reference.pdf) for the current controls.

The Trine HUD bundle is hardware-confirmed. See [validation](VALIDATION.md) for the remaining Instrument-hold display issue.
